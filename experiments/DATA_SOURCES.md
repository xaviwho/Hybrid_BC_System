# Data Source Inventory

Produced by Phase 2, Change 6. This is the factual basis for rewriting Sections
III-H and III-M. Every input to every canonical experiment is listed, with what
generated it, how many records, whether it is real or synthetic, and where it
lives on disk.

**Canonical** = the experiment whose output is consolidated into `RESULTS.json`.
Scripts not listed as canonical do not feed any published number.

---

## 1. Inputs consumed by canonical experiments

| Exp | Input | Generated by | Real / synthetic | N | On disk |
|-----|-------|--------------|------------------|---|---------|
| exp1 | IoT telemetry payloads | `exp1_latency_real.py:payload()` | **synthetic**, deterministic (counter + run nonce; no RNG) | 200/class × 3 classes latency; 50/level × 6 levels × 3 classes throughput | generated in-process; per-request rows persisted to `results/exp1/exp1_requests.jsonl` |
| exp2 | Privacy-policy test records | hand-curated in `exp2_privacy_policy.py` | **curated by hand** (HIPAA / GDPR / PCI / secrets / quasi-ID / benign cases) | 13 records, 57 fields | in-source literal |
| exp3 | Anchor ids + Merkle leaves | `exp3_gas_real.py` (`sha256` over run salt) | **synthetic** inputs, **real** on-chain measurement | 3 single-record + 8 batch sizes × 3 reps = 27 real txs | receipts on the live Ganache chain; tx hashes recorded in results |
| exp4 | Twin state updates | `exp4_lifecycle_real.py:make_state()` | **synthetic**, deterministic | 200 reps/point; 7 rollback targets × 100; 7 storage points × 5 | generated in-process via real `twin_manager` |
| exp5 | Duplicate/distinct ingest payloads | `exp5_exactly_once_real.py:payload()` | **synthetic**, deterministic | 6 sequential + 25 concurrent + 40 distinct = 71 | generated in-process |
| exp7 | Twin version deltas | real `twin_manager` history, `exp7_hadc_real.py:evolve()` | **real deltas** over synthetic state evolution | 4 classes × 500 steps → ~1,996 deltas | generated in-process |
| exp8 | Twin version deltas (2 state models) | real `twin_manager` history, `exp8_recovery_strategy.py` | **real deltas** over synthetic state evolution | 1,001 versions × 2 models; 21 (k,q) points × 100 reps | generated in-process |

**Nothing in the canonical set is loaded from a file.** Every input is generated
deterministically at run time. That is defensible and should simply be stated —
but the manuscript must not imply that operational IIoT datasets drive the
measurements, because they do not.

## 3. FlexSim

**Zero FlexSim events were ever consumed, end-to-end.** No FlexSim file exists
anywhere in the repository. The name survived in three places, all now resolved
or quarantined:

- `experiments/_quarantine_generators/generate_contribution4_panel.py` — quarantined.
- `experiments/exp7_hadc_compression.py` — superseded by `exp7_hadc_real.py`;
  its "FlexSim dataset" was generated in code by `np.random`.
- `experiments/generate_ipo_pipeline.py:67` — the "FlexSim Simulation Traces"
  input box, **removed in Phase 2, Change 6**.

Per the spec, FlexSim is not being added. The real provenance (twin_manager
version deltas) is better and is what the numbers actually come from.
